# Barlow y Barlow Condensed

Diseñadas por Jeremy Tribby. Distribuidas bajo la **SIL Open Font License 1.1**, que permite expresamente el uso, la redistribución y el alojamiento propio.

Texto completo: <https://openfontlicense.org/open-font-license-official-text/>
Origen: <https://fonts.google.com/specimen/Barlow>

Los archivos de este directorio son el subconjunto **latin** en `woff2`, tal como los sirve Google Fonts. Se autoalojan por dos motivos: el `@import` a `fonts.googleapis.com` bloqueaba el render con dos viajes en serie, y `/privacidad` afirma que el sitio no habla con terceros — cargar las fuentes desde Google le entregaría la IP de cada visitante.

Para actualizarlas, pedir el CSS a Google con un *user agent* moderno (si no, devuelve `ttf`), quedarse con los bloques `latin` y descargar cada `woff2`.
